# Welcome to Camunda Issues 

In this repository, you can find Camunda GitHub issues, that we selectively publish by mirroring them from internal repositories, to ensure you can follow along on updates. (Please note that most Camunda products are developed in a public repositories, so you can access issues there directly. However, some components use internal repositories, so that we use this repository to selectively publish individual issues to keep you informed. An example is Camunda Web Modeler).

Please note that next to this repository, you can follow along on updates using the following links:

- [Camunda Roadmap](https://roadmap.camunda.com/)
- Public repositories. Please refer to the respective repositories and their issues to open bugs, features requests, or to learn what we are working on, on a more technical level:
    
    - [Camunda 8 Orchestration cluster: Zeebe, Tasklist, Operate, Optimize, Identity, Camunda 8 Run](https://github.com/camunda/camunda)
    - [Camunda 8 Connectors](https://github.com/camunda/connectors)
    - [Camunda Modeler](https://github.com/camunda/camunda-modeler)
    - [Camunda BPMN JS](https://github.com/camunda/camunda-bpmn-js)

    - [Camunda 8 Helm Chart](https://github.com/camunda/camunda-platform-helm)
